# Project : Smart Classroom Noise Alert System 
The Smart Classroom Noise Alert System is an Arduino-based project that monitors classroom noise using a sound sensor. When the noise becomes too loud, it alerts students using LEDs, a buzzer, an OLED display, and a servo motor.

COMPONENT USED :
1. Arduino Uno  
2. Sound sensor ( In Wokwi there is no sound sensor instead of used push button as a noise )
3. OLED display	
4. Green LED	
5. Yellow LED	
6. Red LED	
7. Buzzer	
8. Servo motor	
9. Resistors
10. Jumper wire of the connection  
3. How does it work?

Step 1: Quiet classroom  
The sound sensor detects a low sound level. The green LED turns on, and the display shows “Quiet.”

Step 2: Moderate noise  
When the sound level increases, the yellow LED turns on, and the display shows “Moderate Noise.”

Step 3: Excessive noise  
If the noise crosses the set limit, the red LED and buzzer turn on. The servo motor moves to indicate a warning, and the display shows “Too Noisy!”  

Short Conclusion  
“The Smart Classroom Noise Alert System is designed to maintain a peaceful learning environment. It detects classroom noise and automatically provides alerts using LEDs, a buzzer, an OLED display, and a servo motor when the noise exceeds the permitted level.”
